# 第四次实验结果分析：多事件揭示的延迟、背景误报与轨迹数耦合

分析日期：2026-10-20。实际批次：[exp004_20261020_201923](outputs/exp004_20261020_201923/)。本次分析读取并核算已完成结果、源码和原图；未重新推理、训练或修改原始输出及人工审核表。

**结论：第三次Whittier暴露的候选缺失只是其中一种瓶颈。新事件同时出现了“早已检出目标但时序复核长期不通过”“框之间关联失败”“背景轨迹持续高分误报”，以及“无关轨迹增加导致正确目标的校准概率下降”。当前四组参数不能统一解决这些问题。下一步应转向有目标位置标注的模块消融，优先研究薄烟复核、稳健关联与目标自身的校准证据。**

**本轮高分辨率设置在Alison将目标轨迹首次跨阈从+39分钟提前至+34分钟，在West从+6分钟提前至+5分钟并消除了该片段的出现前阳性；Cranston仍为+10分钟。低阈值没有提前这三个事件的目标轨迹跨阈，West反而从+6变为+7分钟。联合设置均未早于高分辨率单项。**

**时间口径澄清：本文所有+N分钟均相对官方首次可见烟羽，不是完整序列的绝对帧号。完整第1张为−40分钟，第41张为0分钟，第42张为+1分钟，第43张为+2分钟；绝对第3张则是−38分钟。用户已澄清此前异议来自这两种口径的混淆，因此不将该反馈作为+2分钟帧的云层误检标签。以下恢复原关键位置诊断，但候选归属仍需正式人工标注验证。**

## 5. West：背景被持续高分误判，目标关联也存在临界失败

### 5.1 1024组的出现前阳性来自左侧山地背景

背景轨迹中心约在`cx=0.12～0.13, cy=0.626`，与新生目标烟羽的`cx≈0.61, cy≈0.61`位置不同。核对[−40分钟](../../data/figlib_exp004_three_events/20180706_West_lp-n-mobo-c/1530899281_-02400.jpg)、[−35分钟](../../data/figlib_exp004_three_events/20180706_West_lp-n-mobo-c/1530899581_-02100.jpg)、[−31分钟](../../data/figlib_exp004_three_events/20180706_West_lp-n-mobo-c/1530899821_-01860.jpg)、[0分钟](../../data/figlib_exp004_three_events/20180706_West_lp-n-mobo-c/1530901681_+00000.jpg)和[+6分钟](../../data/figlib_exp004_three_events/20180706_West_lp-n-mobo-c/1530902041_+00360.jpg)的该局部，主要是相同山脊、山谷和地表纹理，没有看到与后来目标一致的新生烟羽。

原版−31分钟背景轨迹L=`4.449389`、跨度10、独立真实观测6、均分`0.139301`，校准概率`0.830147`；到0分钟概率约`0.994817`。因此这是一个对本次目标无效的高分背景报警。只提高最终阈值也难以同时保留弱目标并排除接近0.995的背景。

## 6. 新发现：无关轨迹数量会压低正确目标的概率

实际校准器为：

```text
z = -6.210306878910163
    + 0.6058361824062284 × L
    + 2.1562298048766317 × ln(1 + T)
    + 3.791871985413993 × C
    - 0.5972490381162873 × N
p = sigmoid(z)
阳性阈值 = 0.7207499167831384（对应z约0.948184）
```

L是时序原始输出，T是轨迹跨度，C是条目置信度均值（插值条目的0置信度也参与），N是当前窗口全部保留轨迹数。N不是这条目标轨迹自己的观测次数。

West +6分钟对照：

| 条件 | 原版 | 低阈值 |
| --- | ---: | ---: |
| 目标裁剪框，原图像素 | (1665,1073)至(1940,1349) | 相同 |
| 目标L | 8.835232 | 8.835209 |
| 目标T / 独立观测 | 2 / 2 | 2 / 2 |
| 目标C | 0.436038 | 0.436038 |
| 全部保留轨迹数N | 2 | 4 |
| 目标概率 | 0.877628 | 0.684741 |
| 目标是否跨阈 | 是 | 否 |

低阈值多出的两条干扰轨迹将目标线性得分额外扣去约`1.194498`，足以使其从阳性转为阴性。低阈值组目标到+7分钟才跨阈。其整窗仍被更早的背景报警占据，所以只看整窗阳性会完全掩盖这种退步。

Alison +39分钟也有相同机制：两组目标的几何、T、C及L几乎相同，原版N=1、概率`0.852710`；低阈值N=2、概率`0.761110`，没有带来提前。

这是保存特征层面的明确校准机制，不是把相关性当成裁剪因果。它提示评价和改进需要考虑“添加无关候选是否会削弱已有正确目标”。将N直接设为1只能作为反事实诊断；正式改变特征定义需要在开发集上重新校准，并另行验证误报代价。

原版和低阈值组81个时刻的当前检测框完全一致。两组目标+1分钟有候选、+2分钟形成轨迹，+10分钟才首次跨阈；高分辨率和联合组的这三个时刻也没有改善。

## 8. 运行开销和启动填充需要分别解释

以下按每种设置合计三个新事件；推理耗时为日志中检测与预测墙钟时间之和，含CUDA同步，不含加载、预热、诊断后处理和写文件。

高分辨率本批总耗时较少，与West等片段需要复核的轨迹更少同时发生；不能据一次运行证明1536的单次检测天然更快。联合相对高分辨率增加了64次轨迹评估，没有提前任何一个新事件的目标跨阈。

全972步最长约7.07秒，低于60秒采样间隔。现有证据不支持“计算积压造成10～39分钟延迟”。裁剪阶段仍占有明显开销，例如West原版的有轨迹窗口裁剪中位数约1.97秒、分类器约0.89秒。工程缓存优化和识别证据改善应分别测量。

启动填充还有一个口径问题：West两组1024在−40分钟只有一张真实图片，却经6槽重复填充形成跨度6的保留轨迹；Alison低阈值−38分钟、West联合−37分钟也出现只有1次独立观测的保留轨迹。共4个此类轨迹窗口，均未跨阈。当前`min_detected_entries=2`统计有效槽位，不能统一解释成至少两个独立真实时刻。这个问题影响启动阶段“首次保留轨迹”的口径，但不能解释发生在启动之后的West持续背景阳性。

## 9. 下一步建议：先做能区分原因的实验，再决定改进技术

### 优先级一：补目标位置和困难背景标签，修正评价对象

为四个事件的早期烟羽保留目标区域、可见程度和其他烟雾说明。至少覆盖Whittier和West的0～+7分钟、Cranston的0～+10分钟，以及Alison的0～+40分钟；West出现前40帧作为重点背景核查，再补长时无火片段。明确区分整窗阳性、目标轨迹跨阈、最高分轨迹归属和实际新告警。

这一步可先在已有数据完成。自动汇总计算本身一致，问题在于它没有人工真值，不能承担“首次正确识别”的评价任务。

### 优先级二：用人工提供的位置定位薄烟复核瓶颈

针对Alison和Cranston，固定真实图片与目标位置，在相同中心下比较裁剪上下文和目标尺度；分别报告原始L与完整校准概率。帧数、C、N要明确控制，避免把轨迹长度奖励或背景轨迹数量混进裁剪效果。

人工提供位置只用于诊断，不能计入自动检测成绩。若给出正确位置及合适上下文后仍识别不了早期薄烟，再研究薄烟样本训练、时序表达或更合适的视觉特征；若L明显改善，先改候选几何和裁剪，不急于替换整个时序网络。

### 优先级三：用West做关联和校准的控制实验

固定+4～+6分钟已保存检测框，比较当前IoU关联与包含中心位移、尺度变化的关联策略，观察是否能保住真实移动/扩散烟羽的连续性；同时核查背景误连，不能只降低IoU后报一次提前量。

固定目标L、T、C，先记录改变N的校准反事实；再研究目标自身的观测质量、真实观测数、最近证据和背景区分，重新拟合校准器。West的背景已接近0.995，仅提高最终阈值很难同时解决弱烟延迟和强背景误报。其山地背景应作为困难负样本，验证时保留未用于训练/调参的背景片段。

### 优先级四：再推进更细粒度候选与多事件验证

Whittier和West的+0～3分钟仍未被本轮四组救回，可比较原图局部切片/更高局部分辨率与整图1536的目标候选产生时间，同时记录额外干扰。Alison和Cranston已有早期候选，不能把切片检测当作它们长延迟的充分解决方案。

现阶段可把0.10 / 1536保留为后续对照，但三起新事件加Whittier不足以确定通用最优配置或模型上限；这些事件已参与诊断和参数选择，也不再适合作为最终泛化成绩的唯一依据。是否与预训练数据重叠仍未核实。
