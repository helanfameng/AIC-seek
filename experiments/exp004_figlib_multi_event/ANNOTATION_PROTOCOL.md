## 2. 空框的统一含义

| 状态 | 含义 | 评价用途与边界 |
| --- | --- | --- |
| 官方 0 分钟以前无框 | 尚未到本次事件的官方起点 | 不表示整张图没有其他烟雾 |
| 官方起点以后、首次有框之前无框 | 肉眼不可分辨 | 保留官方事件时间；不作为清晰无烟负样本，也不进入可定位烟羽的逐框漏检分母 |
| 有人工粗框 | 烟羽可见，框为人工估计的整体范围 | 独立位置依据；支持早期裁剪诊断及粗略范围覆盖分析 |
| 后段高分辨率黄框/绿框已基本覆盖，省略补框 | 烟羽可见，未再画独立人工框 | 人工确认覆盖参考高分辨率组；独立精确几何仍缺失 |
| 以后新增标注出现内部断档或无法判断 | 待人工确认 | 不能自动当无烟、不可见或模型已覆盖 |

后段共 77 帧。当前不需要重新画这些框才能开展早期诊断。四种设置共用同一人工事实；后段基本覆盖的确认来源为高分辨率组，**不能推定其余三组的框也覆盖正确**。

不能将黄框、绿框复制为独立人工真值，再评价同一模型。标注者确认高分辨率框基本覆盖烟羽，也不等于其时序分类已正确跨阈或已经发出告警。缺少独立几何框不表示无烟，尚未逐组核验也不表示四组全部覆盖失败。

其他烟雾、困难背景区域和明确的不确定帧标签尚未单独编码，应保留为未记录或待审核，不能据空区域认定没有背景误报。West 0～+2 分钟的不可辨识来自标注者说明，不记成模型漏检三张清晰烟羽。

## 3. 图片、真值与时间轴

- 使用 `event_id/filename` 唯一对应图片，必要时结合采集清单的图片 SHA256；四种设置读取同一套原始人工标注，避免复制四套人工答案。
- 原 VIA 的框为原图像素坐标 `x,y,width,height`；比较时可转换为 `[x0,y0,x1,y1]`，不预先缩放到 1024 或 1536。模型归一化中心框也应转换到相同原图坐标。
- 官方 `t_official=0` 仍是统一基准；完整第 41 张对应 0 分钟。它不是点火时间。时间分辨率为 1 分钟。
- 同时报告 `delay_official=t_correct-0` 和 `delay_human=t_correct-t_first_discernible`。本轮人工首次可辨识时刻：Alison=0、West=+3、Cranston=0 分钟，不改写官方 0 点。
- 滑窗只能读取当前及过去图片；补齐槽位、插值框和重复图片不能增加独立真实观测数。窗口内 `tube_id` 会重新建立，跨窗口同号不代表同一持久对象。

## 4. 分开评价输出阶段

| 量 | 统一定义 | 注意事项 |
| --- | --- | --- |
| `t_candidate` | 首次有经独立位置证据确认属于本次烟羽的当前检测框 | 其他位置先出框不算目标检出 |
| `t_kept` | 首次有经确认属于目标的保留轨迹；另报独立真实观测数 | 同时记录实际模型过滤结果；启动填充不解释为多次独立观测 |
| `t_target_threshold` | 首次有目标轨迹概率达到冻结阈值 | 保存目标身份依据、当前/最近观测时刻；历史框和插值框不能冒充当前检测 |
| `t_winner_target` | 首次整窗阳性且最高分轨迹确属目标 | 与某条目标轨迹跨阈不同；West 原版 +6 分钟可能仍由背景取最高分 |

实际新告警另作部署指标，需要真实触发、去重和复位过程。第四次回放关闭 `compute_trigger`，上述量不能直接称为“系统首次正确发出告警”。

[RESULTS.md](RESULTS.md) 已有目标时间线保留为原诊断结论。现有人工几何只到 Alison +16、Cranston +5 分钟，不能把 +34/+39 和 +10 分钟的跨阈自动升级成全量人工真值验证成绩。关键时刻可补一次目标轨迹身份确认及证据，不要求整段重画框。

## 5. 粗框匹配报告连续量

人工框近似覆盖全部烟羽，检测框可能只落在其中最明显的局部。原因定位统一输出：

- `IoU = 交集面积 / 并集面积`：框形状与尺度的一致程度。
- `reference_box_coverage = 交集面积 / 人工框面积`：人工粗范围被覆盖的比例。
- `prediction_inside_reference_fraction = 交集面积 / 检测框面积`：检测框有多少落在人工粗范围内。
- 检测框中心是否在人工框内；分类器实际扩张、补方及边界裁切后的裁剪覆盖人工框的比例；裁剪原图像素边长与最终 224 输入中的目标尺度。

这些量是几何证据，不单独决定真阳性。仅有交集不能确认烟羽身份，大框覆盖烟区也不等于正确定位。正式匹配门槛应根据独立人工身份审核样例确定、冻结并报告敏感性；本轮不把任意 IoU 阈值当成已验证标准，也不报告精确标注口径的 mAP。

例如 West 原版 +5 分钟，人工框约 269×112，局部检测框有 100% 面积落在其中，但 IoU 约 0.240。若将 IoU≥0.5 当作唯一目标身份门槛，会排除这类局部候选，影响关联瓶颈诊断。

## 7. 第五次实验的控制方式

**Alison / Cranston：** 现有早期框已经可以启动首轮裁剪诊断。固定图片时刻、有效帧列表、权重、224 输入、独立观测数及校准 T/C/N；在固定人工中心下比较裁剪边长和上下文。若比较检测中心与人工中心，单设中心变化对照。每次保存裁剪坐标、粗框覆盖率、目标尺度、原始 L、完整校准 p。人工提供的位置只用于诊断，不纳入自动检测成绩。

不在有框时段之前自动插值人工位置，也不用后来的烟羽范围定位早期窗口。若加入更早帧或改变采样数量，另设时间输入对照，避免与裁剪变化混在一次效果比较里。

**West：** 使用已有框检查目标位置，固定 +4/+5/+6 分钟检测框比较关联策略，保存连接/分裂和独立观测数；再固定保留轨迹及 L/T/C，只改变 N 或校准映射做反事实诊断。改变正式校准特征后须重新拟合，并在独立数据上验证；令 N=1 的反事实不直接当作部署改进。

原结果中的 West 左侧山地局部核查可作为待确认困难背景区域的起点，不把整段空 VIA 当作已完成负样本标注。可以一次确认稳定区域及适用时间，再检查其他干扰；四组仍共用这些背景事实。

## 8. 最终比较的主要指标与护栏

主报告采用**同一误报预算下的事件发现比例与延迟**：逐事件列出官方延迟、人工可辨识延迟、截止观察终点是否命中及漏检事件数。到 +40 分钟仍未确认目标输出的事件记为未命中/右删失，不能赋为 0、+40，或从平均延迟中静默删除。提前量只在双方均命中的同一事件配对计算，同时保留完整命中表。

误报预算尚未由独立背景数据确定，暂不指定“最佳阈值”。开发阶段报告多个可达到的误报预算点及检测曲线；开发集选定阈值和告警策略后冻结，再用于未参与改进的新事件与背景。指标单位是事件，972 个重叠窗口不是 972 起独立事件。

背景护栏同时记录：

1. 人工确认背景上的阳性窗口占比与持续时间；分母只包含对应审核区间。
2. 连续背景阳性段数及每摄像头小时的段数。诊断约定相邻 60 秒点持续阳性合为一段，一个明确阴性点即分段；未知标签不跨越合并，边界截断单独标记。这是回放输出段，不是实际通知次数。

采样点代表的 60 秒区间用于计算暴露量，片段边界与未知区间明确处理，不用图片数量直接冒充摄像头小时。当前每事件有官方出现前 40 个采样区间，三事件名义合计 120 分钟；全画面其他烟雾仍未完成审核，不能据此发布总体误报率或声称四组已达到相同误报水平。推理耗时及显存作为计算成本另报。

## 9. 最小补充信息

1. West 出现前山地等干扰区：确认背景身份及适用时间；其他烟雾和无法判断的区域单独标记。稳定区域可加时间段，不必重复画 40 次。
2. 正式重算四组首次正确跨阈时，优先确认 Alison +34/+39、Cranston +10 及相邻边界帧的目标轨迹身份。高分辨率后段基本覆盖已确认，其他三组仍需核验。
3. 仅在确有歧义的帧补不确定标记；不要求重画 43 个已有框或全部后段。

这些缺口不妨碍先开展早期裁剪诊断；完整背景误报和后段正式成绩待相应证据到位后计算。三个事件均已参与诊断和参数选择，按开发事件管理；最终验证另留未用于训练、校准或调参的事件与背景，保留原版和高分辨率对照。
