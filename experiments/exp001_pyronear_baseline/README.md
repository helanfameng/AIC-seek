- 目的：验证本机预训练推理流程，检查候选框；未重新训练。
- 本项目代码：首次试跑发生于建立本仓库之前，没有当时的本仓库提交号。首次发布提交收录当次推理脚本；后续实验记录运行前的Git提交号。

- 数据：`data/figlib_whittier_smoke_10`，同一固定相机10张3072×2048原图，每60秒一张，相对首次可见烟羽0～540秒。

## 参数

YOLO置信度阈值0.1，输入尺寸1024，NMS IoU 0.2；关联IoU 0.2，至少2次实际检测；稳定裁剪，context_factor 1.5，裁剪224×224；最大20帧；不足6帧采用symmetric填充；最终logistic阈值0.7207499167831384。按模型包默认设置运行，未开启首次触发时刻计算。

## 运行命令

从仓库根目录运行（输出到outputs，以免覆盖历史记录）：

```powershell
& .\.venv\Scripts\python.exe .\run_sequence.py `
  --sequence .\data\figlib_whittier_smoke_10 `
  --model .\models\v0.6.0\model.zip `
  --output .\outputs\exp001_rerun.json `
  --device cuda
```

## 实际结果

- 输入10帧，无截断、无输入填充。
- `is_smoke=true`；最高保留轨迹概率 `0.9937540430233742`。
- 保留1条轨迹，索引4～9（第5～10张）。
- `first_crossing_frame=null`：首次在线报警时间未计算。
- 耗时、峰值显存：未记录。

查看 [predictions.json](predictions.json)；下载仓库后用浏览器打开 [visualization.html](visualization.html)，可逐帧开关黄色框。页面中的YOLO分数不是逐帧时序概率。

## 观察与限制

第2～4张已经可见薄烟，但未出现在保留轨迹中。现有JSON不足以区分“检测器未提出候选”和“轨迹关联/筛选丢弃”，不能直接断定时序分类器漏检。后期框偏向烟柱较浓的下部，未覆盖全部淡烟；黄色检测框不同于时序分类器扩展后的实际裁剪窗口。

整段概率不是准确率；第5张轨迹起点不等于第5张已经报警。对逐步增长的历史序列独立运行才能评估在线发现时间，避免使用未来帧的信息。采样间隔限制了时间结论的精度。图片与训练数据是否重叠未核实；单个有烟样例不能测量误报率或泛化性能。

发布时仅将JSON和页面中原本的本机绝对数据路径改为仓库相对路径，预测值与框坐标保持不变。
