# 实验七实现口径与消融定义

本实现是冻结Pyronear特征上的**PSL思想区域分类适配**，不是原像素级分割代码的逐行复现。来源：[PSL作者仓库](https://github.com/LujianYao/psl)、[核心实现](https://github.com/LujianYao/psl/blob/main/mmseg/models/decode_heads/PSL_main.py)。方法参考核对日期为2026-10-23；训练运行另对本地源码、协议、输入与权重记录指纹。

## 共同输入与训练

每个候选沿用实验六的因果8×16×384缓存。取当前帧16个格点的均值，得到384维区域向量；不把候选标签广播成像素标签。特征缺失时，所有新增方法都退回官方原概率，缺失候选与无候选时刻仍参与完整事件/正常时长评价。

共享投影为LayerNorm(384)→Linear(384,32)→GELU→Linear(32,32)，再L2归一化。基础属性为原时序logit/10、log1p(轨迹跨度)、平均检测置信度、候选数/10。各组共享同维度融合头：32维投影＋4个基础属性＋2个外观分类logit→64→ReLU→1。

C0/C1外观分类为32→2线性层；原型组使用与各类别原型的最大余弦相似性/0.15。公共投影与融合头使用相同初始化随机流，避免原型模块参数量不同导致公共头初值变化；参数量仍如实报告，不称为完全相等。

基础训练损失为最终二分类BCE＋0.25×外观两类交叉熵。按序列逆窗口数抽样，使每个事件/正常片段的预期权重相等；BCE正类权重由该抽样分布的正负质量计算。验证按序列等权平均最终BCE选最佳轮次，BES或SupCon损失不直接参与最佳轮次选择。只使用已确认的train/val候选；不确定、缺特征及未确认正常片段不进入监督训练。

默认30轮、耐心5轮、批量64、AdamW学习率0.001、权重衰减0.0001、梯度裁剪1。每个种子独立训练；未训练图像编码器、检测器或原时序Transformer。

## 分组

| 名称 | 实现 |
|---|---|
| R0 | 官方原分数；阈值仍由本轮验证集确定，官方默认阈值可在旧实验中另查 |
| C0 | 普通外观线性层与共同融合头 |
| P1 | 每类1个原型 |
| P2 | 每类2个原型 |
| P3 | P2＋0.05×BES适配损失 |
| P4 | P2＋PUO适配更新 |
| P5 | P2＋BES＋PUO适配 |
| C1（可选） | C0＋0.1×监督对比损失，只用不同事件的同类样本组成正对 |

原型用训练特征初始化：先取类中心，再用最远样本扩充多原型。小批次的原型归属在真实类别内部用Sinkhorn计算；不会把背景分配到烟类别原型。类别/原型没有足够样本时明确跳过相应散度计算，日志记录有效BES批次。

## BES稳定化适配

沿用作者代码的总散度S_T与按原型分组的类内散度S_W构造、S_B=S_T−S_W，以及最小一组广义特征值绝对值之和的倒数。

本实现的明确差异：

1. 从像素改为区域向量，维数32，底部特征值数8；作者配置使用更高维像素表示，不能照搬其样本规模。
2. 对S_W添加0.001I正则，通过Cholesky构造对称矩阵L⁻¹S_BL⁻ᵀ后求特征值，避免直接求逆或对非对称矩阵调用对称特征分解。
3. 分母加入1e−6；至少2个原型组各有2个以上样本才激活该批次BES。梯度与参数必须有限，否则停止并保存失败记录。
4. 保留作者代码的“底部特征值取绝对值”选择，不把它改写成未经说明的全新Fisher损失。

## PUO稳定化适配

PUO不是额外加一个普通正交惩罚。这里在加正则的总散度度量下，对原型做Stiefel流形切向更新和极分解回缩：

- 将原型列映射至S_T的平方根度量，极分解得到正交列；
- 使用标签约束的原型均值构造目标，将更新方向投影到Stiefel切空间；
- 步长0.05更新后再次极分解回缩，再映射回原特征空间、逐原型归一化。

与作者实现的明确差异：作者包含特殊原型替换、非梯度更新及其特定矩阵变换；本区域适配在共同AdamW步骤后追加上述度量约束更新，使用正确配对的平方根/逆平方根及稳定回缩。因此P4/P5的结论只能归属于本区域适配，不能冒充原像素PUO的完全复现或原论文复现成绩。

原型多样性不意味着自动获得“云、雾、薄烟”等人工语义子类；类别命名与早期薄烟保护仍需额外证据。

## 校准与评价

复用实验六纯评价函数，保留相同正常时间积分、5分钟误报段合并、最高分区域决定正确定位的定义。每个新增方法只在验证正常片段中选满足≤0.1段/小时和≤1%超阈占比的最低阈值，测试不调阈值。当前验证时长不足30小时，属于诊断数据限制；即使测试零误报也不宣称长期误报率为零。

输出召回、5/10分钟召回、漏检窗口、条件中位延迟、逐事件配对提前量、误报次数与持续时间。额外输出首个正确候选、任一正确候选跨阈时刻和错误区域获胜时刻数，以区分候选不足与排序失败。

新版10例包括已经用于分析的原8例，整体称为修订诊断集。两段替代序列年代较早，与官方预训练数据重叠未知。正常数据、旧实验五种方法的冻结复评、PSL分支结果分别保存，不能用换数据或改工作点伪装算法增益。
